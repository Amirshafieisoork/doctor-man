اتصال دیجی‌پی

اطلاعات فنی پذیرنده را فقط در همین فرم وارد کنید.

درگاه پرداخت دیجی‌پی

هر چهار مورد باید از دیجی‌پی و برای محیط انتخاب‌شده دریافت شده باشد. نام کاربری و رمز این بخش، اطلاعات فنی API پذیرنده هستند؛ رمز حساب شخصی یا مقدار دلخواه نیستند.

اگر فقط Client ID و Client Secret دارید، نام کاربری و رمز API پذیرنده را از پشتیبانی فنی دیجی‌پی بگیرید. برای اولین ثبت امن، هر چهار مورد را وارد کنید. پس از آن، کادر خالی اطلاعات امن فعلی را حفظ می‌کند.

وضعیت اتصال هنوز دریافت نشده است.

با تغییر محیط، هر چهار اطلاعات مخصوص محیط جدید را دوباره وارد کنید.

آزمون اتصال فقط ورود فنی به دیجی‌پی را بررسی می‌کند؛ سفارش یا پرداختی ایجاد نمی‌کند و هیچ مبلغی برداشت نمی‌شود.

هوش مصنوعی رایگان

تنظیم تحلیل تصاویر و پاسخ‌های هوش مصنوعی با حساب رایگان Groq

Groq · حساب Free

کلید را از صفحه کلیدهای Groq بردارید. محدودیت‌های حساب رایگان را هم می‌توانید ببینید.

فقط از کلید حساب Free استفاده کنید. این تنظیم، حساب را به پلن پولی ارتقا نمی‌دهد. پایان سهمیه با پیام مشخص اعلام می‌شود و تحلیل به سرویس پولی منتقل نمی‌شود.

وضعیت کلید هنوز دریافت نشده است.

کلید ذخیره‌شده نمایش داده نمی‌شود. برای نگه داشتن کلید فعلی، این کادر را خالی بگذارید.

آزمون اتصال، یک تصویر ساختگی را با کلید ذخیره‌شده می‌خواند؛ اطلاعات کاربران ارسال نمی‌شود.
